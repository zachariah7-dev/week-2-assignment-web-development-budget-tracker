 Budget Tracker
 Project Description
Budget Tracker is a simple webpage created using HTML and CSS.
It helps users understand how to organize and track daily expenses.
This project was built as part of an HTML and CSS assignment.

Project Files
 1. index.html
This file contains the structure of the webpage.

It includes:
o	A heading and logo image.
o	An expense form.
o	A category dropdown with five expense categories.
o	A table with four columns and five sample expenses.
o	A collapsible help section using details and summary.
o	An embedded YouTube video.
o	A footer.

 2. style.css
This file controls the appearance of the webpage.
It includes:
•	Page colors, spacing, and layout.
•	Form and button styling.
•	Table borders and a colored header.
•	Alternating table row colors.
•	Hover effects for table rows.
•	Focus effects for form inputs.
•	Advanced CSS selectors.
•	Responsive styling for mobile screens.
 3. README.md
This file describes the project, its features, and its files.
 Features
o	Expense form with name, amount, category, and date fields.
o	Five category choices: Food, Transport, Rent, Entertainment, and Other.
o	Five sample expense records.
o	Interactive collapsible instructions.
o	Embedded budgeting video.
o	Responsive page layout.
o	Advanced CSS selectors.
	           Technologies Used
o	HTML5

 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Ensure you have an internet connection for the external image and video.
